## 新增 Save Text File 节点
- 用户按截图（Save Text File 节点）要求：保存文本，可自定义前缀/后缀/保存路径。
- `SaveTextFile`：输入 `text`、自定义 `output_dir`（留空→ComfyUI temp）、`filename_prefix`、`filename_suffix`、`extension`、`encoding`(utf-8/utf-8-sig/gbk/latin-1)、`add_timestamp`、`overwrite`；输出 `file_path`(STRING)。
- 文件名规则：`前缀[+时间戳]后缀.扩展名`；同名自动加 `_1/_2` 计数。自测通过（UTF-8/GBK、目录、计数、temp 回退）。
